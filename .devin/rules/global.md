# Global Rules

## Language and Output

- Always respond to the user in Japanese.
- Write all code comments in English.
- End inline comments with a period (`.`).
- Write all git commit messages and release notes in English.

## PHP Documentation

- Add PHPDoc to PHP classes, functions, and methods whenever possible.
- Do not end the first sentence of a PHPDoc summary with a period:
  - Method header summary.
  - Class header summary.
  - File header summary.

## Coding Standards

- Follow WordPress Coding Standards (WPCS).
- Use Yoda conditions when WPCS reports them (for example, `0 === $var`).
