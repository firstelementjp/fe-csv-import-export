# ⭐ Pro 版機能

このページでは **FE CSV Import & Export Pro** が提供する機能とその使い方を説明します。

Free 版と Pro 版は連携して動作します。両方のプラグインをインストール・有効化し、ライセンスキーを認証すると Pro 機能が利用可能になります。

!> このページの機能はすべて、有効なライセンスを持つ **FE CSV Import & Export Pro** が必要です。

## 機能比較

| 機能 | Free | Pro |
| ---- | :--: | :-: |
| CSV インポート / エクスポート | ✓ | ✓ |
| カスタムフィールド（`cf_` プレフィックス） | ✓ | ✓ |
| タクソノミーカラム（階層対応） | ✓ | ✓ |
| 自動バッチ処理 | ✓ | ✓ |
| Dry Run 差分プレビュー | ✓ | ✓ |
| 差分の全量 CSV ダウンロード | — | ✓ |
| ACF フィールド（`acf_` プレフィックス） | — | ✓ |
| Direct SQL エクスポート | — | ✓ |
| スケジュール実行 | — | ✓ |
| UpdraftPlus データベースバックアップ | — | ✓ |
| 実行パスワード / 再認証 | — | ✓ |

## ライセンスの有効化

1. [製品ページ](https://www.firstelement.co.jp/products/fe-csv-import-export-plugin/) でライセンスを購入
2. 販売サイトのマイアカウントページからライセンスキーをコピー
3. **ツール → FE CSV Import & Export → License** タブを開き、キーを入力
4. ライセンスを有効化すると Pro 機能と自動アップデートが利用可能になります

ライセンスが有効になるまで Pro 機能は表示されません。

## ACF フィールド対応

Advanced Custom Fields のデータを、フィールドの書式を保持したままインポート/エクスポートします。

- CSV カラムに `acf_{フィールド名}` を指定すると ACF フィールドとしてマッピングされます（例：`acf_price`）
- Taxonomy フィールドの値は可読な名前でエクスポートされ、複数値フィールドは標準の `|` 区切りを使用します
- Text, Number, Select, Checkbox, Taxonomy, User, File, Relationship, Repeater, Flexible Content など主要なフィールドタイプに対応
- ACF プラグインがインストール・有効化されていることが必要です。追加の設定は不要です

## スケジュール実行

インポートとエクスポートを1回限りの予約ジョブとして登録し、バックグラウンドで後から実行できます。

### ジョブの作成

1. **エクスポート** または **インポート** タブで通常通り設定を行う
2. **実行タイミング** で **後で実行するようにスケジュール** を選択
3. **開始時刻**（WordPress サイトのタイムゾーン）を指定。必要に応じて **完了または失敗時にメール通知** を有効化
4. 実行を開始すると、即時実行の代わりにジョブとして登録されます

登録したジョブは **Schedules** タブに一覧表示され、Pending（保留）・Running（実行中）・Completed（完了）・Failed（失敗）・Cancelled（キャンセル）のステータスで管理されます。

### ジョブの実行方式

- ジョブは WP-Cron 経由で実行されます。アクセスの少ないサイトでは WP-Cron の起動が遅れることがあるため、各ジョブには Schedules タブに表示される **シークレットトリガー URL** があります。正確な開始時刻にしたい場合は、サーバーの cron からその URL を叩いてください
- ジョブの種類： 1回限りのインポートまたはエクスポート（WP 互換モードのみ）
- スケジュールインポートは自動カラムマッピングで実行され、対話式のマッピング確認ステップはスキップされます
- インポートの場合、CSV はジョブ作成時に Web ルート外のプライベートなスケジュールストレージにステージングされます

### ジョブの管理

- **Run**：保留中のジョブを即時実行
- **Cancel**：保留中または実行中のジョブをキャンセル
- **Rotate**：シークレットトリガー URL を再生成
- **Download CSV**：完了したエクスポートの結果をダウンロード
- **Delete**：終了したジョブを削除

自分が登録したジョブのみ管理できます。サイト管理者はすべてのジョブを管理できます。

!> FE CSV Import & Export（Free 版）**1.1.0 以降**が必要です。

## Dry Run 差分の全量 CSV ダウンロード

Free 版の Dry Run プレビューは、画面上に最大100行分のフィールド単位の差分を表示します。Pro 版ではドライラン実行後に差分エリアへ **Download full diff (CSV)** ボタンが表示され、プレビューに表示されない行を含む **全行分の完全な差分** を CSV でダウンロードできます。

!> FE CSV Import & Export（Free 版）**1.1.0 以降**が必要です。

## Direct SQL エクスポート

エクスポートタブの標準エクスポートボタンの隣に **Export (Direct SQL)** ボタンが追加されます。WordPress のコア関数をバイパスしてデータベースを直接クエリするため、エクスポート性能を最大化できます。大規模データセットや高度なワークフロー向けの機能です。

## UpdraftPlus データベースバックアップ

バックアッププラグイン [UpdraftPlus](https://updraftplus.com/) がインストール・有効化されている場合、**高度な設定** タブに **インポート実行前に UpdraftPlus データベースバックアップを実行** のオプションが表示されます。有効にすると各インポートの前に自動でデータベースバックアップが実行されるため、問題が起きてもすぐに復元できます。

## 実行パスワードと再認証

実行時のアクセス制御を追加します。専用の **Execution Password** タブ（管理者のみ）で設定し、インポートとエクスポートをそれぞれ独立して設定できます。

- **ログインパスワードを要求**：実行のたびに操作者自身のアカウントパスワードの再入力を求めます
- **実行パスワードを要求**：このタブで設定した共通パスワードを要求します
  - **毎回確認**：実行ごとに入力を求めます
  - **時間枠を許可**：指定した分数（1〜1440）が経過するまで再入力を省略します

実行パスワードの変更には管理者自身のログインパスワードが必要です。
